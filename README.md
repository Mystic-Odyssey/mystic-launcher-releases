# Mystic Odyssey — le launcher

Les versions publiées du launcher de Mystic Odyssey : l'installateur et les fichiers que lit sa mise à jour automatique. Le code du launcher est privé.

Télécharger : [la dernière version](https://github.com/Mystic-Odyssey/mystic-launcher-releases/releases/latest) (`Mystic-Odyssey-Setup-<version>.exe`, Windows). Une fois installé, le launcher se met à jour tout seul.

Mystic Odyssey est un projet indépendant et n’est pas affilié à Mojang Studios et à Microsoft.
